웹앱 주소는 어디서 복사하나요?
  1. 구글 시트 CSO_미니CRM → 확장 프로그램 → Apps Script
  2. 오른쪽 위 배포 → 배포 관리 → 기존 배포본 수정(✏️)
  3. 액세스 권한: 모든 사용자 → 버전: 새 버전 → 배포
  4. 나오는 웹앱 URL(끝이 /exec)을 복사해 위 칸에 붙여넣기

※ 주소를 모르겠으면 같은 화면의 배포 관리에서 기존 배포본의 URL을 다시 복사할 수 있습니다.
